# Neon Analog Clock

A responsive analog clock inspired by the supplied reference image, built with HTML5, CSS3, and vanilla JavaScript. No JavaScript libraries are required.

## Run it
1. Extract the project folder.
2. Open `index.html` in a modern browser.

For local development, you can also open the folder in VS Code and use the Live Server extension.

## Files
- `index.html` - semantic markup and clock face structure
- `style.css` - responsive layout, neon bezel, typography, shadows, and clock styling
- `script.js` - real-time hand movement and digital time display

## Customize
- Change the colors near the top of `style.css` in `:root`.
- Remove the Google Fonts import in `index.html` if you prefer a fully offline font stack.
- The clock uses the viewer's local device time.
